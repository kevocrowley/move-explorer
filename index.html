How many atoms is that? (rough estimates)

The This game count adds up the options offered in the one game on the board. It grows slowly: chess never has more than 218 options in a position, draughts usually has fewer than 10, a Scrabble rack can have thousands, and a Go board starts with 361. The Shannon count multiplies them, because each option branches into a whole new game. That is the number to compare with about 1.33×1050 atoms on Earth. It's an estimate that assumes every branch has as many options as the line actually played (Shannon's method).
